# examples/

短いプログラムサンプルです。

```sh
uv run play.py hello
```

| | テスト内容 | 行数 |
| --- | --- | --- |
| `hello.py` | `m.tick()`が1フレーム。文字を出す。ESCで戻る | 16 |
| `text.py` | 文字をセルにそろえる。中央ぞろえ、右ぞろえ、文字スクロール | 68 |
| `car.py` | `m.key()`でキーを読む。ドット絵を`m.sprite()`で置く | 36 |
| `scroll.py` | 通し座標を画面の座標に直す。多重スクロール | 31 |
| `catch.py` | 当たり判定と得点 | 69 |
| `tall.py` | `Buffer`で仮想画面を作り、窓で切り取って見せる | 44 |

書き方は[../PROGRAMS.md](../PROGRAMS.md)にまとめてあります。
`examples/`の下でも`programs/`と同じで、pygameとPillowは使いません。
画面・入力・時間はすべて`Machine`を通します。

## memo

- 画面は **120x7ドット**。5x7ドットの文字セルが24個ならんだ1行です。
- セルとセルのあいだの1ドットは物理的に存在しないので、文字を置くxは
  5の倍数にします。
- `m.tick()`が1フレームの区切りです。`False`を返したら`return`します。
- ESCは`m.pressed("BRK")`です。どの例でも押せば戻ります。
